# 🚗 Car Classifier Project

An intelligent vehicle classification application powered by Machine Learning and Computer Vision built with Python.

## 📌 Features
- Automated vehicle brand and model classification from images.
- Feature extraction and deep learning model inference pipeline.
- Flexible web API and evaluation scripts.

## 🛠️ Tech Stack
- **Language**: Python 3
- **Machine Learning**: PyTorch / TensorFlow, OpenCV, Scikit-Learn
- **Tools**: Jupyter Notebook, Git
